01 SaaS · IA & Web

Liora — Plateforme SaaS avec IA

Application web en ligne réunissant un générateur de CV, un résumeur de PDF et un correcteur de texte via l’API Gemini. Conçue pour expérimenter une architecture complète : authentification JWT, base PostgreSQL pilotée avec Drizzle ORM et déploiement sur Vercel.

ArchitectureNext.js · React 19 · TypeScript · PostgreSQL · Drizzle ORM · Gemini AI · JWT

02 Desktop · Python

Folder Compressor — Outil bureau open source

Utilitaire de bureau doté d’une interface graphique moderne (thème AMOLED) qui compresse en lot chaque sous-dossier sélectionné en archive .zip, .cbz ou .7z. Intègre le filtrage de file d’attente, les extensions personnalisées et une protection contre l’écrasement.

TechnologiesPython · Tkinter · zipfile · Licence MIT
